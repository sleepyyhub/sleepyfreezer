## Markdown cheat sheet

- `# Heading` — big title, `##` smaller, `###` smaller still
- `**bold**` → **bold**, `*italic*` → *italic*
- `- item` — bullet list
- `1. item` — numbered list
- `` `code` `` — inline code
- `[link text](https://example.com)` — a link
- `> quoted text` — blockquote
- `- [ ] task` / `- [x] done` — checkboxes
