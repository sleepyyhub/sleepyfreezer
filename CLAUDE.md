Guidance for AI assistants (Claude Code and others) working in this repository.

## What this repository is

This is a **single-file repository**. The one tracked artifact is:

- `sleepytradefreezer` — an **obfuscated Lua/Luau script** (a Roblox script).

Despite what `file(1)` reports (it guesses "JavaScript" from the syntax), the
content is Lua/Luau. This is confirmed by:

- The header comment `--[[ v1.0.0 https://wearedevs.net/obfuscator ]]` — a
  Lua block comment identifying the [WeAreDevs Lua obfuscator](https://wearedevs.net/obfuscator).
- Lua/Luau runtime identifiers used at the bottom of the file: `getfenv`,
  `_ENV`, `newproxy`, `setmetatable`, `getmetatable`, `unpack`, `select`.
- The overall shape `return(function(...) ... end)(...)`, decimal string
  escapes (`\110\088\114...`), and a numeric-opcode VM interpreter — all
  hallmarks of this obfuscator's output.

The file has **no extension**, is a **single line** (~48 KB, ~48,000-character
line), and is fully obfuscated. It is machine-generated output, not
human-authored source.

## Working with the obfuscated file

**The `sleepytradefreezer` file cannot be meaningfully hand-edited.** It is
obfuscated output: variable names are stripped, strings are encoded as numeric
escapes, and control flow runs through a generated bytecode VM. Any manual edit
to the middle of the line will almost certainly corrupt the script.

Because of this:

- **Do not attempt to refactor, reformat, or "clean up" the obfuscated file.**
  Reformatting (e.g. adding newlines, running a Lua formatter) will change or
  break it and provides no benefit.
- **Do not try to beautify or pretty-print it as JavaScript.** It is not
  JavaScript; JS tooling will produce garbage or errors.
- If the script's *behavior* needs to change, the correct workflow is to edit
  the **original, un-obfuscated source** (which is not present in this repo) and
  re-run the obfuscator, then replace this file with the new output. If a user
  asks for a behavioral change, first ask them for the original source — do not
  try to patch the obfuscated blob.
- **Preserve the file exactly** (name, no extension, single line, no trailing
  reformatting) unless the user explicitly provides replacement content.

### Inspecting the file

To understand its structure without corrupting it, read-only inspection is fine:

```bash
head -c 2000 sleepytradefreezer      # peek at the header + start
wc -c sleepytradefreezer             # byte count
grep -o 'wearedevs[^ ]*' sleepytradefreezer   # confirm the obfuscator source
```

Prefer piping large output to a pager or byte-limited `head` — the single line
is long enough to overwhelm terminals and tool output limits.

## Git workflow

- Default branch: `main`.
- Commit history is small and uses terse messages (e.g. "Update
  sleepytradefreezer", "Create sleepytradefreezer"). Each commit typically
  replaces the whole file with a freshly obfuscated version.
- When committing, keep messages short and descriptive of the change (e.g. the
  version or behavior that changed), consistent with the existing history.

### Branch and push rules for AI agents

- Develop on the branch you were assigned for the task; create it locally if it
  does not exist.
- Push with `git push -u origin <branch-name>`. On network failure, retry up to
  4 times with exponential backoff (2s, 4s, 8s, 16s).
- **Never** push to a different branch without explicit permission, and do not
  open a pull request unless the user explicitly asks for one.

## Conventions summary

- Treat `sleepytradefreezer` as an **immutable, generated binary-like blob**,
  not editable source.
- Never introduce JavaScript/Node tooling — the language is Lua/Luau.
- Do not add build/test scaffolding unless the user asks; there is currently no
  toolchain and none is expected for a distributed obfuscated script.
- Keep the repository single-purpose: it exists to host and version this one
  script.

## Notes / open questions to raise with the user

- If asked to modify the script's logic, request the **original pre-obfuscation
  source** and the obfuscation step; the obfuscated file alone is not a viable
  editing target.
- If asked what the script does, note that its behavior is not statically
  determinable from the obfuscated form without deobfuscation or running it in a
  Roblox/Luau environment — describe it from user-provided context rather than
  guessing.
