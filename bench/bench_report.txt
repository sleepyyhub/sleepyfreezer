CAVEATS, so the numbers are not read as more than they are:
  - This is a container CPU, not the M3 Air. Absolute values will differ;
    the ratio between the two versions is the part that carries over.
  - InvokeServer here is a Lua stub (~35-45 ns). The real one is a C call
    that serialises and queues the packet, so it costs more. It costs the
    same in both versions, so the delta stands.
  - The game's own handler is a synthetic 400-iteration loop (~3.3 us).
    The real NotificationController builds GUI and plays a sound, so the
    thing pole saves is far larger in the actual game than shown here.
  - Everything above is Lua work only. It says nothing about the wire or
    about the network send step the packet waits for after the invoke.
