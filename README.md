# Sleepy Legends — Anime 3D RPG 🌸⚔️

Ein anime-inspiriertes 3D-Action-RPG im Browser, gebaut mit Three.js.

## Starten

```bash
npm install
npm run dev
```

Dann im Browser öffnen: **http://localhost:5173**

## Steuerung

| Taste | Aktion |
|---|---|
| **WASD** | Bewegen |
| **Maus ziehen** | Kamera drehen |
| **Mausrad** | Zoom |
| **Shift** | Sprinten |
